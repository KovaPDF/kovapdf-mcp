# Security

Please report a security problem in this package or in the KovaPDF service by email to support@kovapdf.com.
Do not open a public issue for it.

How KovaPDF handles files, encryption and reports: https://www.kovapdf.com/security
Security contact file: https://www.kovapdf.com/.well-known/security.txt

This package holds no keys or secrets. Never put an API key or token in an issue, a pull request or a file here.
